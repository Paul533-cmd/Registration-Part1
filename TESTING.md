# Part 1 Testing

## Unit Testing

The project uses JUnit to test the registration and login functionality.

The tests cover:

- Valid and invalid usernames
- Valid and invalid email addresses
- Valid and invalid passwords
- Valid and invalid South African cell phone numbers
- Successful registration
- Invalid registration details
- Successful username login
- Successful email login
- Failed login
- Login status messages

Additional validation tests were added to check specific invalid
input conditions.

The complete test suite should pass before the project is submitted.
