# Registration-Part1

## PROG5121 Programming 1A - Part 1

This project implements a registration and login system using Java.

## Features

- Username validation
- Password complexity validation
- South African cell phone number validation
- Email address validation
- User registration
- Login using username or email
- JUnit unit testing

## Technologies

- Java
- Apache NetBeans
- Apache ANT
- JUnit 4

## Testing

The project contains JUnit tests for the registration and login functionality.

The current test suite contains 19 passing tests.
